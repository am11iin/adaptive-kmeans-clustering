# Adaptive K-Means Clustering

An advanced implementation of the K-Means clustering algorithm with adaptive split and merge mechanisms using Python and scikit-learn.

---

## 📌 Features

- Dynamic cluster splitting
- Automatic cluster merging
- Dispersion-based clustering
- PCA visualization
- Clustering evaluation metrics
- Adaptive number of clusters

---

## 🧠 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- scikit-learn

---

## ⚙️ Installation

Install required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn
```

---

## 🚀 Run the Project

Run the script:

```bash
python adaptive_kmeans.py
```

---

## 📂 Dataset

The project uses:

```text
user_behavior_dataset.csv
```

Dataset preprocessing includes:

- Missing value handling
- One-hot encoding
- Feature scaling

---

## 📊 Evaluation Metrics

The project evaluates clustering using:

- Silhouette Score
- ARI (Adjusted Rand Index)
- NMI (Normalized Mutual Information)

---

## 📈 Visualization

The project visualizes clustering results using PCA dimensionality reduction.

---

## 🎯 Project Goal

The objective of this project is to improve traditional K-Means clustering by dynamically adapting the number of clusters through split and merge operations.
